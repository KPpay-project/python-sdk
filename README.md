# KPPAY Gateway Python SDK

Official Python SDK for the KPPay API. A Pythonic interface for integrating KPPay payments into Python applications and services.

## Status

**Early development—SDK implementation is not yet available.**

This repository is the starting point for the KPPAY Gateway Python SDK. It does not yet contain a working SDK, installation instructions, published packages, or a supported API feature set.

## Intended ecosystem

Python applications and backend services; Python packaging tools are the intended distribution ecosystem.

## Reference

The [KPPAY Gateway TypeScript SDK](https://github.com/KPpay-project/typescript-sdk) provides a related implementation reference. Its language-specific code and support claims do not apply to this repository.
